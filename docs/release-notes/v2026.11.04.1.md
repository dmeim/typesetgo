# v2026.11.04.1 — Word goals in Connect, and more settings for the host

**Date:** November 4, 2026

## Added

- **Word goal, a new Connect test.** The host sets a number of words (500, 1,000, 2,500, 5,000 or their own, up to 100,000) and everyone types toward one shared total.
  - Only correct, finished words count: a word adds to the total once the student presses space and it matches exactly.
  - Students see the room's total and their own count above their typing. The live board shows a big tally, in fullscreen and on the pop-out board too, with each student's words on their card.
  - The total updates about once a second, so a full class typing doesn't flood the room with updates.
  - Words keep coming until the goal is reached, and reaching it ends the test for everyone, followed by the usual results.
  - Students who join partway through start typing right away instead of waiting for the next test.
  - Only Together rooms can use a word goal. Own pace turns off while the list has one, and own-pace rooms don't offer it.
- **More in Everyone gets.** The host can now also set the theme's look, lines shown, words per line and the keyboard style (Spotlight, Finger guide, Keycaps or Legacy).
- **Kid-friendly.** One button in Everyone gets sets big text, short lines, the finger guide and no ghost for the whole room. It leaves the tests as they are.

## Changed

- The label under "Test 1 of 2" no longer repeats a test's name, so an untitled quote reads "Quote · any length" instead of "Quote · Quote · any length".

## Deploy notes

- **Deploy Convex first** (`bun run convex:deploy`), then the frontend. The new frontend sends tests and settings the old backend would reject.
- No data migration. The schema only gains the optional `connectRooms.goalTally`, the `goal` test mode and optional override fields. Rolling the schema back later needs those kept, or the rooms that use them cleaned up first.
- New internal Convex functions: `connect.goalTotal`, `connect.tallyGoal` and `connect.publishGoalTally`.
