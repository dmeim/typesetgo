# v2026.10.27.3 — A settings pill that holds still

**Date:** October 27, 2026

## Changed

- **Mode is the first row of the test settings pill**, followed by Length (or Text for Preset) and then Difficulty and Extras. Switching modes now only adds or removes rows below Mode instead of moving it, so the pill no longer jumps around while you pick.

## Deploy notes

- Frontend only. No Convex changes and no data migration.
